# 更新记录

## 1.0.10

- 根目录配置移入 config，更新记录与第三方声明移入 docs，构建、测试、日志和设计输出归入 artifacts
- 保留根目录双击入口与打包入口，开发、构建、测试和发布同步使用新路径
- 打包、许可复制和风格检查脚本改用 TypeScript，纳入严格类型检查
- 风格检查覆盖普通注释、CSS 注释和 HTML 内联脚本，补充类型断言与忽略检查指令的识别测试
- 集中维护点半径、折线默认比例、编号、层级、拟合阶数和坐标文本限制，界面与文件校验共用来源
- 合并存档和字体菜单的键盘操作，复用路径序列化和普通对象校验，清除失效的图标注册与旧注释
- 修复缺失坐标被当成零、复制名称超过文件限制及复制函数位置与定义不一致的问题

## 1.0.9

- 显示中的坐标轴加入优先吸附，并参与与曲线、边框的交点计算
- 交点图标改为两条相交直线与实心交点
- 新建几何点统一使用 A–Z、A1–Z1、A2–Z2 的点名顺序，批量创建和几何构造共用命名规则
- 坐标点自动生成独立点名文字，补齐旧存档中缺少文字的坐标点
- 函数与拟合曲线旁显示解析式，拟合结果改变时同步更新，导出也保留说明
- 平移、缩放和来源拖动后同步绘制锁标记，直线标记锚定实际方向点

## 1.0.8

- 源码按应用、核心模型、画布、几何、数学、界面、存储、对象和样式分类，保留根目录启动入口
- 增加射线和直线，两次点击分别确定起点与方向，显示和导出按范围裁剪
- 几何区增加角平分线，生成的线统一为直线并默认锁定，两点工具改为两点直线
- 增加固定数学坐标轴、缩放自适应刻度和与实际距离一致的比例尺
- 点工具支持输入多个坐标点，数学坐标可在属性中修改
- 使用 mathjs 绘制单变量函数，支持解析式和定义域编辑，在无效值与渐近线处断开
- 使用 ML.js 实现线性和多项式拟合，拟合结果随来源点移动而更新
- 几何点放置和拖动优先吸附函数曲线与图形边框，再吸附网格
- 新对象复用颜色、线宽、虚线、透明度、隐藏、撤销和保存，多选支持统一透明度
- 增加 Ctrl+H 隐藏选区，修复空白区平移异常，空白处左键直接拖动平移，右键或 Shift+左键框选
- 锁标记按对象固定几何位置绘制，不再随无限线的视口裁剪外框跳动

## 1.0.7

- 原地长按左键后拖动可平移画布，快速拖动继续操作对象或绘图
- 隐藏左侧平移图标，保留空格临时平移和原有快捷键
- 所有几何构造支持先选工具再依次选择来源，保留先选来源的方式
- 存档选择改为独立弹出菜单，统一名称居中、行高、间距与选中状态
- 存档、字体与工具分组菜单支持重复点击收起
- 几何构造默认锁定，端点沿原方向伸缩，显示长度随存档保存，来源移动或转动后继续联动
- 构造对象可在对象管理中解锁，解锁后首次移动或改变角度时解除关联
- 统一名称、正文、说明、旋转角度、线宽与选区的配置来源，界面输入和文件校验使用同一限制

## 1.0.6

- 修复导出预览尺寸溢出，窄屏导出按钮保留完整的无障碍名称

- 图形和线条标签支持选中并转为独立文本，保留字体、颜色和位置

- 文字配置单独设计字体菜单与对齐图标，移除实验性下拉框布局
- 可配置参数提前并补充中文说明，共享限制由界面和文件校验统一引用
- 全项目检查基础写法、类型、注释与配置来源，删除旧工具栏样式和未使用的边界计算
