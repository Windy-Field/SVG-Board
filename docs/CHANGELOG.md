# 更新记录

## 1.0.10

- 修复空白坐标被当成 0、复制后的对象名称可能超长，以及复制函数曲线后位置与解析式不一致的问题
- 角平分线图标改为两条角边、中间的平分线和两段等分角弧

## 1.0.9

- 显示中的坐标轴参与优先吸附，也参与与曲线、图形边框的交点计算
- 交点图标改为两条相交直线与实心交点
- 新建几何点按 A–Z、A1–Z1、A2–Z2 的顺序命名，批量创建和几何构造使用相同规则
- 坐标点自动显示独立的点名文字，并为旧存档中的坐标点补齐缺失的点名
- 函数曲线和拟合曲线旁显示解析式，拟合结果变化时文字同步更新，导出时也会保留
- 修复平移、缩放或拖动来源点后锁标记不同步的问题，直线的锁标记固定在确定其方向的点上

## 1.0.8

- 增加射线和直线工具，用两个点确定起点与方向；显示和导出时，程序会按可见范围或导出范围裁剪线条
- 几何工具增加角平分线，构造出的线统一为直线并默认锁定；两点工具改为“两点直线”
- 增加固定原点的数学坐标轴，刻度随缩放调整，比例尺与画布中的实际距离对应
- 支持批量输入坐标点，也可以在属性中修改点的数学坐标
- 支持绘制单变量函数，并编辑解析式和定义域；遇到无效值或检测到曲线跳变时会断开绘制
- 支持线性和多项式拟合，来源点移动后，拟合曲线会自动更新
- 放置或拖动几何点时，优先吸附函数曲线和图形边框，再吸附网格点
- 新对象支持原有的颜色、线宽、虚线、透明度和隐藏设置，也可以撤销或保存；多选对象时可统一调整透明度
- 增加 Ctrl+H 隐藏选区，修复空白区平移异常：左键直接拖动空白处即可平移，右键或 Shift+左键拖动用于框选
- 锁标记固定在对象的几何位置，修复直线裁剪范围变化时标记跳动的问题

## 1.0.7

- 在原地长按左键后拖动可以平移画布，快速拖动仍用于操作对象或绘图
- 隐藏左侧平移图标，保留空格键临时平移和原有快捷键
- 所有几何构造都支持先选工具，再依次选择来源对象，也保留先选来源对象的操作方式
- 存档选择改用独立弹出菜单，名称居中显示，并统一行高、间距和选中状态
- 存档、字体和工具分组菜单展开后，再次点击入口即可收起
- 几何构造默认锁定，构造线的端点可以沿原方向伸缩，显示长度随存档保存；来源对象移动或转动后，构造对象会跟随变化
- 构造对象可以在对象管理中解锁，解锁后首次移动或改变角度时，会解除关联并转为独立对象

## 1.0.6

- 开发服务监听源码变化时，也会更新离线文件；双击入口通过刷新参数载入文件
- 双击入口优先连接正在运行的本地画板服务，服务关闭时打开离线文件
- 修复导出预览超出窗口的问题，窄屏下的导出按钮也保留完整的无障碍名称
- 统一下拉框样式，使存档名称与箭头居中，并移除存档旁重复的新建图标
- 移除第二行工具栏，将网格、撤销和重做按钮依次放在自动吸附按钮右侧
- 图形和线条标签可以选中并转为独立文本，转换时保留字体、颜色和位置
- 画布颜色随作品保存；网格点加深并放大，深色画布使用浅色网格
- 放大左侧工具图标，并根据工作区高度调整尺寸
- 文字配置改用独立的字体菜单和对齐图标，替换原来的下拉框布局

## 1.0.5

- 画图存档移到标题栏，通过下拉菜单选择，加号、只读和吸附按钮放在存档区域旁
- 对象管理替换图层页签，集中提供选择对象、调整层级、锁定和隐藏操作
- 隐藏按钮和属性控件按对象编号操作，修复隐藏目标错误的问题；隐藏来源对象后，关联对象仍会显示并参与几何计算
- 对象列表和画布增加锁定标识，锁定对象仍可选中并解锁
- 图形支持拖动或两次点击放置，圆通过圆心和圆上一点确定尺寸
- 椭圆工具分为圆和任意椭圆，两点线段可以使用已有点，也可以点击空白位置创建来源点
- 右键框选根据可见笔画和对象范围判断，也可以重新框选已有的多选对象
- 放大并居中右侧页签和标题，仅可编辑区域的界面文字允许选择
- 保存按钮只写入本地存档，导出窗口使用透明背景，并提供项目文件下载

## 1.0.4

- 提高删除按钮悬停时的对比度，统一主要按钮和选中按钮的状态样式
- 矩形圆角默认为零，箭头头部改为开放尖角
- 放置文字、几何点和图形时，可以拖动控制尺寸；曲线绘制后可以调整方向控制点
- 自动吸附默认开启，依次优先选择交点、端点与顶点、边框和网格
- 同一位置连续单击可以轮换选择重叠对象，点名可以单独移动和隐藏
- 存档按内容去重，两个内置作品加入画图存档
- 作品标题只显示名称，界面标题与浏览器标签页共用钢笔图标

## 1.0.3

- 放置对象后保留当前工具，支持连续绘制
- 调整工具和属性面板的布局，增加选区上方的文字配置栏，修复标题被压缩的问题
- 增加正方形、正多边形、自定义多边形和贝塞尔曲线，并支持编辑曲线控制点
- 连接线增加折点手柄，可以单独调整中段路线
- 画布可以持续平移，保存和导出时按实际内容范围裁剪，并保留少量留白
- 说明栏支持 Markdown 编辑，预览时会过滤不安全的内容，说明随作品保存
- 面板、菜单和对话框增加出现与退出动画，并适配系统的减少动态效果设置
- 编辑器可以构建为直接打开的独立 HTML 文件
- 修复参考线条无法拖动、竖直箭头方向错误和文本框空白区域无法选中的问题
- 线条改用起点和终点手柄，端点支持网格吸附，直接编辑关联线时会解除该线的约束
- 加深网格并略微增大字体，统一左侧工具图标的尺寸与对齐方式
- 几何构造移入左侧工具栏，线条和文本工具可以长按切换模式
- 右侧栏可以显示或隐藏，入口按钮同步显示选中状态
- 增加只读模式、本地多存档、新建存档和删除确认
- 支持 Ctrl 多选、右键框选，以及再次单击已选对象取消多选
- 重做两份参考存档，三角形顶点名称使用独立文本框
- 提示只保留关键内容，末尾不加标点

## 1.0.2

- 页面左下角显示北京时间和应用版本，时间每秒更新
- 窄屏下状态栏分行显示，完整保留日期时间和缩放操作

## 1.0.1

- 绘制完成后自动选中新对象，可以接着拖动、缩放或旋转
- 鼠标悬停时显示对象轮廓，修复细线在空白区域被误选的问题
- 隐藏线段和箭头边缘中间的缩放手柄，修复从笔画中间无法拖动的问题
- 框选、Shift 多选和图层选择使用相同的锁定规则，修复组合后首次拖动无效的问题
- 拖动时直接更新关联对象和标签的位置，保留选区与图层顺序
- 按住空格可以临时平移，Escape 可以撤回未完成的变换，触控操作取消时会清理草稿
